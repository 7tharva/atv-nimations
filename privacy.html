Privacy Policy

Applies to: Shorts Uploader (Google Cloud project "Shorts Uploader"). Last updated: 6 November 2026.

Who we are

Shorts Uploader is a private tool operated by the owner of the ATV-nimations YouTube channel. It runs only on the owner's own computer and is used only to publish the channel's own videos. Contact: atharva1121.as@gmail.com.

YouTube API Services

Shorts Uploader uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

When the channel owner signs in with Google, the app requests two permissions:

  • Manage your YouTube videos (youtube.upload): to upload the owner's video files with their title, description, tags and privacy settings.
  • View your YouTube account (youtube.readonly): to read the signed-in channel's name, so the app can confirm it is uploading to the correct channel, and to check that an uploaded video finished processing.

The app does not access comments, subscribers, analytics, viewers' information or any other user's data.

How data is used and stored

  • The Google sign-in token is stored only in a local file on the owner's computer and is used only to call the YouTube Data API on the owner's behalf.
  • Video files and their descriptions are created by the owner and sent only to YouTube.
  • A local log records which videos were uploaded (file name, YouTube video ID, title, time).
  • No data is sold, shared with third parties, used for advertising, or sent anywhere other than Google/YouTube.
  • This website uses no cookies, analytics or trackers. It is hosted on GitHub Pages; see the GitHub Privacy Statement.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page at myaccount.google.com/permissions. Deleting the local token file and the upload log on the owner's computer removes all data the app keeps. To ask a question or request deletion, email atharva1121.as@gmail.com.

Children

Shorts Uploader is used only by the adult channel owner. It does not collect data from viewers of any age. Some ATV-nimations videos are marked as made for kids on YouTube, and YouTube applies its own protections to those videos.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
